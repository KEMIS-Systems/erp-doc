# Clientes

Lista todas as empresas-clientes vinculadas ao cadastro do fornecedor —
ou seja, os clientes do KEMIS ERP para os quais esse fornecedor presta
serviço e por isso tem pendências de documentos e/ou formulários de
avaliação a resolver.

## Listagem

| Coluna | Descrição |
| --- | --- |
| Nome | — |
| Razão social | — |
| Documento | CNPJ ou CPF |
| Email | — |
| Telefone | — |
| Docs. pendentes | Quantidade de documentos aguardando envio ou correção para esse cliente |
| Formulários pendentes | Quantidade de formulários de avaliação pendentes para esse cliente |

Todas as colunas, exceto a de número da linha, podem ser ordenadas
clicando no cabeçalho. Não há filtro de busca nem botão de ação por linha
nesta tela — ela serve apenas para o fornecedor visualizar rapidamente
quantas pendências tem com cada cliente. Para resolver as pendências, use
**[Arquivos](./arquivos.md)** (documentos) e
**[Formulários de avaliação](./formularios.md)** (questionários), que já
reúnem os itens de todos os clientes num só lugar.
