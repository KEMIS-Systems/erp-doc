# Assinaturas

Lista os documentos enviados para assinatura eletrônica em que o
fornecedor é um dos destinatários — sejam eles gerados a partir de um
**[Formulário de avaliação](./formularios.md)** que exige assinatura, ou de
qualquer outro processo do cliente.

## Listagem

| Coluna | Descrição |
| --- | --- |
| Documento | Título do documento |
| Cliente | Empresa-cliente relacionada ao documento |
| Destinatário(s) | Nome/email de cada signatário, com um selo verde ao lado de quem já assinou |
| Status | Ver tabela abaixo |
| Enviado em | Data de envio para assinatura |

### Status possíveis

| Status | Significado |
| --- | --- |
| Aguardando envio | Ainda não foi enviado para os signatários |
| Aguardando assinatura / Visualizado | Enviado; aguardando ação de um ou mais signatários |
| Parcialmente assinado | Alguns signatários já assinaram, outros ainda não |
| Assinado | Todos os signatários assinaram |
| Recusado | Um signatário recusou a assinatura |
| Cancelado | O documento foi cancelado antes de ser concluído |
| Expirado | O prazo para assinar terminou |

## Ações

| Ação | Descrição |
| --- | --- |
| Ver documento | Baixa e abre o arquivo em uma nova aba, sem alterar o status |
| Assinar | Só aparece quando o fornecedor é o destinatário e a assinatura ainda está pendente; abre em nova aba a página externa do provedor de assinatura eletrônica |

**Passo a passo:**

1. Na listagem, localize o documento (ou chegue até ele pelo bloco
   "Documentos aguardando assinatura" do **[Painel](./dashboard.md)**).
2. Opcionalmente, clique em **Ver documento** para conferir o conteúdo
   antes de assinar.
3. Clique em **Assinar** — o fornecedor é levado à plataforma de
   assinatura eletrônica, fora do Portal, onde efetivamente assina (ou
   recusa) o documento.
4. Ao concluir na plataforma externa, o status é atualizado
   automaticamente aqui no Portal: para Assinado (se todos já assinaram)
   ou Parcialmente assinado (se ainda faltam outros signatários).
5. Se o documento veio de um formulário de avaliação aguardando
   assinatura, confirmar a assinatura conclui automaticamente o envio
   desse formulário.

Não há botão de download separado — "Ver documento" já abre o arquivo em
uma nova aba, de onde é possível salvá-lo pelo próprio navegador. A recusa
de assinatura também é feita na plataforma externa, não dentro do Portal.
