# Usuários

Cadastro dos colaboradores do fornecedor que também podem acessar o
Portal com login próprio, vinculados à mesma conta.

## Listagem

| Coluna | Descrição |
| --- | --- |
| Foto | Avatar; clique para ver, trocar ou remover |
| Nome | — |
| Email | — |
| Celular | — |
| Online | Indica se o usuário está com sessão ativa no momento |
| Último acesso | Data/hora do último login e validade da sessão |
| Registro | Data de criação e quem criou |
| Atualização | Data da última alteração e quem alterou |

Há um campo de busca por nome/email no topo da lista.

## Cadastrar ou editar um usuário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Nome | **Sim** | — |
| Email | **Sim** | — |
| Celular | Não | — |
| Senha | Não | Pode ficar em branco tanto ao cadastrar quanto ao editar |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| **+** (adicionar) | Abre o formulário de cadastro de um novo usuário |
| Editar | Abre o formulário para alterar os dados do usuário selecionado |
| Apagar | Remove o usuário selecionado, com confirmação |
| Clicar na foto | Se o usuário já tem foto: abre uma visualização com opções de trocar ou remover; se não tem: abre direto o envio de uma nova foto |

O usuário titular do fornecedor (o primeiro criado, junto com o cadastro
da empresa) não pode ser editado nem apagado por esta tela, e nenhum
usuário pode apagar a si próprio. As ações de editar e apagar também
dependem do nível de permissão do usuário que está logado.

Esta tela não tem um campo para definir grupo de acesso ou permissões por
usuário — todos os colaboradores cadastrados aqui têm acesso equivalente
ao Portal.
