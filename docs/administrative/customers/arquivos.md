# Arquivos

Repositório de documentos do próprio cliente (não confundir com a página
**[Arquivos de contrato](./arquivos-de-contrato.md)**, que mostra os
arquivos de cada contrato). Esta é a mesma listagem de arquivos que também
aparece embutida na página **Arquivos do cliente** de cada contrato desse
cliente.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Tipo de arquivo | **Sim, apenas ao adicionar** | Tipo de arquivo do cliente/fornecedor |
| Descrição | Não | — |
| Data de vencimento | Não | — |
| Arquivo | **Sim, apenas ao adicionar** | O arquivo em si |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Anexa um novo arquivo. Também é possível criar um novo tipo de arquivo diretamente por este formulário |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita a descrição/vencimento do arquivo. Indisponível para arquivos privados quando o usuário não tem Acesso avançado, e para arquivos gerados automaticamente pela matriz de exigências |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o arquivo. Mesmas restrições da edição |
| ![ShowFile](/img/icons/ShowFile.png) Ver arquivo | Abre o arquivo |
