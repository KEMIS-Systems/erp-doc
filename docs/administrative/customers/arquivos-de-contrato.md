# Arquivos de contrato

Lista, em modo de apenas leitura, os arquivos anexados aos
**[Contratos](../contracts/index.md)** deste cliente — os mesmos arquivos
visíveis na página **Arquivos** de cada contrato individualmente. A única
ação disponível é abrir/visualizar o arquivo; não há cadastro, edição ou
exclusão por esta página — isso é feito a partir do próprio contrato.
