# Contatos

Cadastra as pessoas de contato do cliente. Esta mesma página existe
também no detalhe de **[Fornecedores](../vendors/contatos.md)**.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Nome | **Sim** | Nome do contato |
| Email | Não | — |
| Telefone | Não | — |
| Celular | Não | — |
| Departamento | Não | Departamento do contato dentro do cliente |
| Cargo | Não | — |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Cadastra um novo contato |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita um contato existente |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o contato |

Os contatos cadastrados aqui aparecem no campo "Contato" do formulário de
**[Contratos](../contracts/index.md)** vinculados a este cliente.
