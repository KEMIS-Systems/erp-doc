# Colaboradores

Lista, em modo de apenas leitura, os colaboradores do módulo de Recursos
Humanos mobilizados para o contrato, com a situação de conformidade de
treinamentos e exames médicos de cada um. Não há cadastro por esta tela —
a mobilização de um colaborador para um contrato é feita em
**Recursos Humanos › Mobilizações de força de trabalho**.
