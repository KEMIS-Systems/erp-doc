# Arquivos do cliente

Exibe os arquivos cadastrados para o cliente dono do contrato — a mesma
listagem acessível pelo detalhe do cliente em
**[Clientes](../customers/index.md)**. Diferente da página **Arquivos** deste
mesmo contrato (que guarda documentos do contrato em si), esta página
mostra documentos que pertencem ao cliente como entidade, e por isso são
compartilhados entre todos os contratos que ele tiver.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Tipo de arquivo | **Sim, apenas ao adicionar** | Tipo de arquivo do cliente |
| Descrição | Não | Descrição do arquivo |
| Data de vencimento | Não | — |
| Arquivo | **Sim, apenas ao adicionar** | O arquivo em si |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Anexa um novo arquivo ao cliente |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita a descrição/vencimento do arquivo |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o arquivo |
| ![ShowFile](/img/icons/ShowFile.png) Ver arquivo | Abre o arquivo |
