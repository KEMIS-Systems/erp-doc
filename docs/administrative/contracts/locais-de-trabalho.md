# Locais de trabalho

Cadastra os locais de trabalho vinculados ao contrato, usados para alocar
colaboradores mobilizados para esse contrato.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Local de trabalho | **Sim** | Nome do local |
| Comentários | Não | Texto livre (aceita formatação) |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Cadastra um novo local de trabalho |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita um local de trabalho existente |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o local de trabalho |
