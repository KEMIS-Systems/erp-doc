# Usuários

Vincula usuários do sistema ao contrato.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Usuário | **Sim** | Usuário do sistema a vincular ao contrato |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Vincula um novo usuário ao contrato |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o vínculo do usuário com o contrato |

O próprio usuário logado não pode remover seu próprio vínculo com o
contrato por esta tela.
