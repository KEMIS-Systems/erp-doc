# Aprovadores

Define quem aprova as respostas, quando o formulário exige aprovação
("Requer aprovação do formulário de avaliação" habilitado).

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Escopo | **Sim** | Formulário inteiro ou Seção |
| Seção | **Sim, se Escopo = Seção** | — |
| Usuário | **Sim** | Usuário responsável por aprovar |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Cadastra um novo aprovador |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita um aprovador existente |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o aprovador |
