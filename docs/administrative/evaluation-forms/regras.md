# Regras

Define quais fornecedores devem responder este formulário.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Fornecedor | **Sim** | — |
| Obrigatória | Não | Interruptor |
| Ativa | Não | Interruptor; regras inativas deixam de exigir resposta |
| Início da vigência | Não | — |
| Fim da vigência | Não | — |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Cria uma nova regra |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita uma regra existente |
| ![Trash](/img/icons/Trash.png) Apagar | Remove a regra |

Um mesmo fornecedor não pode ter mais de uma regra para o mesmo
formulário.
