# Seções

Subdivide o departamento em unidades menores, cada uma com seu próprio
gestor.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Seção | **Sim** | Nome da seção |
| Gestor | Não | — |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Cadastra uma nova seção |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita uma seção existente |
| ![Trash](/img/icons/Trash.png) Apagar | Remove a seção |
