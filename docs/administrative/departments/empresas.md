# Empresas

Vincula o departamento a uma ou mais empresas do cliente. Só aparece
quando o cliente tem mais de uma empresa cadastrada. Cada vínculo define
um gestor responsável por aquele departamento naquela empresa, e
opcionalmente uma seção.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Empresa | **Sim** | — |
| Seção | Não | — |
| Gestor | **Sim** | — |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Vincula uma nova empresa ao departamento |
| ![Pencil](/img/icons/Pencil.png) Editar | Edita um vínculo existente |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o vínculo |
