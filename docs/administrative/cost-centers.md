# Centros de custo

Esta tela cadastra os centros de custo usados para classificar despesas e
alocações em outras partes do sistema — por exemplo, no cadastro de
colaboradores no módulo de Recursos Humanos. É um cadastro simples, de nome
e código, sem tela de detalhe própria.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Centro de custo | **Sim** | Nome do centro de custo |
| Código | Não | — |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Abre o formulário de cadastro de um novo centro de custo |
| ![Pencil](/img/icons/Pencil.png) Editar | Abre o formulário para alterar os dados do centro de custo |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o centro de custo |

Esta tela não tem página de detalhe (sem botão de visualizar) — toda a
edição é feita diretamente pelo formulário de edição.
