# Tipos de exame

Esta tela cadastra os tipos usados para classificar cada agendamento de
exame — por exemplo, admissional, periódico, demissional ou mudança de
função. O cadastro é simples, com apenas um campo de texto livre, e serve
de base para a tela de **[Agendamentos](./schedules/index.md)**, onde cada
agendamento precisa indicar um desses tipos.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Tipo de exame | **Sim** | Nome do tipo de exame (ex.: Admissional, Periódico, Demissional) |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| ![Pencil](/img/icons/Pencil.png) Editar | Abre o formulário para editar o nome do tipo de exame |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o tipo de exame. A exclusão pede confirmação antes de ser efetivada |

Editar, apagar e cadastrar um novo tipo de exame ficam disponíveis apenas
para usuários com nível de acesso mais alto na tela. O sistema não
impede a exclusão de um tipo que já esteja em uso em algum agendamento
— por isso vale conferir em Agendamentos se o tipo está sendo usado
antes de apagá-lo.
