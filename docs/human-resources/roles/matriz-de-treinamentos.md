# Matriz de treinamentos

Lista, em modo somente leitura, os cursos que compõem a matriz de
treinamentos exigida para o cargo, com o contrato ao qual cada exigência
está vinculada (quando a exigência for específica de um contrato, e não
geral para o cargo em qualquer contrato). Não há cadastro por esta tela: a
exigência de um curso para um cargo é definida em
**[Matriz de Treinamentos](../../training-management/trainings-matrices.md)**,
no módulo Treinamentos.
