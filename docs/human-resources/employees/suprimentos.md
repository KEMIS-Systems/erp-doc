# Suprimentos

Lista, em modo somente leitura, o histórico de solicitações de materiais e
suprimentos feitas ao almoxarifado para o colaborador — código, data de
registro, usuário que atendeu, status e data de aprovação. O cadastro e o
atendimento das solicitações são feitos no módulo Almoxarifado.

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| ![ShowFile](/img/icons/ShowFile.png) Ver arquivo | Abre o relatório da solicitação. Disponível apenas para solicitações já servidas ou entregues |
| Exportar (PDF) | Gera um PDF da listagem de solicitações de suprimentos do colaborador |
