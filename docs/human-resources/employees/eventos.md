# Eventos

Histórico de situações do colaborador ao longo do tempo — por exemplo
Ativo, Férias, Afastamento médico, Licença maternidade, Alocado, Demitido
ou Aposentado — cada uma com data de início, data de término opcional e
uma descrição livre.

## Formulário

| Campo | Obrigatório | Descrição |
| --- | :---: | --- |
| Status | **Sim** | Situação do colaborador naquele evento |
| Data de início | **Sim** | Data em que o status passou a valer |
| Data final | Não | Data em que o status deixou de valer |
| Descrição | Não | Observação livre sobre o evento |

## Ações disponíveis

| Ação | Descrição |
| --- | --- |
| Adicionar | Registra um novo evento na linha do tempo do colaborador |
| ![Pencil](/img/icons/Pencil.png) Editar | Altera o status, as datas ou a descrição do evento |
| ![Trash](/img/icons/Trash.png) Apagar | Remove o evento |
