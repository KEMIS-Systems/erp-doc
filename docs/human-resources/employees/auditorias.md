# Auditorias

Log de auditoria do colaborador, gerado automaticamente pelo sistema, sem
nenhum cadastro manual: cada alteração relevante do colaborador — dados
cadastrais, escala/eventos, contratos, atividades críticas, matriz de
treinamentos, matriz de exames médicos ou arquivos — gera uma entrada
aqui, com a ação realizada e as datas e usuários de registro e
atualização.

Não é possível adicionar, editar ou apagar entradas por esta tela.
