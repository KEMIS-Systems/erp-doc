# Perfil

Reúne a foto e os dados do usuário logado, e é o único lugar para trocar a
própria senha. É aberta pelo ícone de engrenagem na barra superior, em
qualquer tela do Portal.

## Foto

O botão de câmera sobre a foto abre um modal para adicionar (se ainda não
houver foto) ou trocar a foto atual, com opção de recorte antes de salvar.

## Dados pessoais e da empresa

Nome/razão social, documento (CNPJ), telefone, email e endereço completo
são exibidos, mas **somente para leitura** — não podem ser editados por
esta tela. Para corrigir esses dados, é preciso falar com o cliente ou com
a KEMIS.

## Alterar senha

O botão **Alterar senha** abre um formulário com três campos, todos
obrigatórios:

| Campo | Descrição |
| --- | --- |
| Senha atual | — |
| Nova senha | Recomendado: pelo menos uma letra maiúscula, uma minúscula, um número e 8 caracteres |
| Confirmar senha | Precisa ser igual à nova senha |

Se a nova senha e a confirmação não coincidirem, o sistema avisa "Senhas
não correspondem" e não envia a alteração. Ao confirmar com os dados
corretos, a senha é atualizada imediatamente.
