# KEMIS ERP

O KEMIS ERP é uma plataforma web voltada para a gestão de empresas de
pequeno, médio ou grande porte, organizada em módulos — Administrativo,
Recursos Humanos, Gestão de Treinamentos, Saúde Ocupacional, e assim por
diante — que podem ser combinados de acordo com o plano contratado (veja
**[Pacotes comerciais](/docs/packs)**).

## Como este manual está organizado

Cada módulo do menu lateral do sistema tem uma seção própria aqui no
manual. Dentro de cada seção:

- a primeira página explica **para que o módulo serve**, quais são suas
  principais funcionalidades e como as páginas dentro dele se relacionam;
- as demais páginas cobrem, uma a uma, cada página (**controller**) do
  módulo — os mesmos itens que aparecem no submenu lateral do ERP —, com o
  que cada formulário pede e o que cada ação disponível faz.

Esta reescrita está sendo publicada por módulo. Hoje cobre **Administrativo**,
**Recursos Humanos**, **Gestão de Treinamentos** e **Saúde Ocupacional** — os
demais módulos do sistema entram em rodadas seguintes.
